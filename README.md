# Citas_M-dicas
Este proyecto fue desarrollado como parte de mi tesis universitaria en la Universidad Veracruzana. Su objetivo es optimizar la gestión de citas médicas en comunidades locales, ademas con la posibilidad de que los mismos pacientes agenden sus propias citas.
